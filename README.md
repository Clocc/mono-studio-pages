# MONO STUDIO 静态页面

这是一个不依赖构建工具的静态页面，可直接部署到 GitHub Pages。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，例如 `my-site`。
2. 上传本目录中的 `index.html`、`styles.css`、`script.js`。
3. 打开仓库 `Settings` → `Pages`。
4. 选择 `Deploy from a branch`、分支 `main`、目录 `/ (root)`，点击 `Save`。
5. 等待几分钟后访问 `https://你的用户名.github.io/my-site/`。

页面没有后端，也没有 API 密钥；可以直接公开。
